# Support

Thanks for using the KMP Project Wizard! Here is where to go for help:

- **Documentation** — start with the [README](README.md) and the plugin
  website at [kmpwizard.oreshkov.app](https://kmpwizard.oreshkov.app).
- **Bug reports & feature requests** — open a
  [GitHub issue](../../issues/new/choose) using the issue templates. Requests
  about the *generated project* (templates, dependencies, architecture) belong
  in [kmp-ledger](https://github.com/aoreshkov/kmp-ledger/issues) instead —
  the templates are generated from that repository.
- **Pro licensing & purchases** — licenses are sold and managed through the
  [JetBrains Marketplace plugin page](https://plugins.jetbrains.com/plugin/31786);
  billing questions are handled by JetBrains Marketplace support.
- **Security issues** — please do **not** open a public issue; report privately
  as described in [SECURITY.md](SECURITY.md).
- **Private contact** — <kmpwizard@oreshkov.app>.

Please note this project is maintained in spare time — responses may take a few
days. See [CONTRIBUTING.md](CONTRIBUTING.md) if you would like to help.
