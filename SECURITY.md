# Security Policy

## Supported Versions

Only the latest release published on
[JetBrains Marketplace](https://plugins.jetbrains.com/plugin/31786) receives
security fixes.

| Version | Supported |
| ------- | --------- |
| latest Marketplace release | ✅ |
| older releases | ❌ |

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately:

- Email: **kmpwizard@oreshkov.app**
- Or use GitHub's private vulnerability reporting ("Report a vulnerability"
  under the repository's **Security** tab), if enabled.

Include the plugin version, IDE build, and reproduction steps where possible.
You can expect an acknowledgement within 7 days. Please allow a reasonable
disclosure window before publishing details; fixes ship as a new Marketplace
release.
